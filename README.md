# MC 核心文件仓库 (mc-core)

本仓库收集整理 Minecraft 服务端「核心」(服务端程序本体) 文件，按来源分类存放：

- `nukkit/` — Nukkit 系列核心 (`.jar`)，适用于 Minecraft 基岩版 (Bedrock) 的服务端。
- `pm/` — PocketMine-MP 内核 (`.phar`)，同样面向基岩版的服务端核心。

所有文件保持原始目录结构上传，文件名与本地一致（含中文与版本标注）。

## 文件直链

每个文件对应的 GitHub Raw 直链（可直接下载 / 引用）整理在 👉 **[文件直链.md](文件直链.md)**

## 说明

- 仓库为 **公开 (public)** 仓库，任何人可通过 Raw 直链直接下载。
- 文件较大（单仓库约 820 MB），建议使用直链或 `git clone` 获取。
- 若文件名含中文 / 特殊字符（如 `[]`、版本号），直链已做 URL 编码，可直接使用。
